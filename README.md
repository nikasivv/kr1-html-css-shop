# FloraShop — учебный цветочный интернет-магазин

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт цветочного магазина: букеты, композиции и комнатные растения. Проект выполнен без CSS-фреймворков, JavaScript используется только для открытия модального окна и проверки формы.

## Обязательные страницы

| Страница | Содержание |
|---|---|
| `index.html` | hero-блок, преимущества, популярные букеты, отзывы, акция, модальное окно быстрой заявки |
| `catalog.html` | хлебные крошки, категории, блок фильтров, 6 карточек товаров |
| `product.html` | букет «Нежность»: изображение, описание, цена, кнопка заявки, таблица состава |
| `order.html` | форма заявки и блок «Как проходит заказ» |

У каждой страницы уникальные `title` и `meta description`, общее меню и подключён `css/style.css`.

## Как выполнены требования КР

- **Семантика:** `header`, `nav`, `main` (один на странице), `section`, `article`, `aside`, `footer`.
- **Навигация:** единое меню на всех страницах, активный пункт (`site-nav__link--active`), якорные ссылки `index.html#advantages` и `index.html#popular`, хлебные крошки на внутренних страницах.
- **Карточки:** блок `product-card` с изображением, категорией, названием, описанием, ценой, кнопками «Подробнее» и «Заказать»/«В заявку».
- **Таблица:** `specs-table` с составом букета на странице товара — `caption`, `thead`, `tbody`, `th`, `td`.
- **Форма:** страница `order.html` и модальное окно на главной; у каждого поля `label` с `for`, `id`, `name`; `required`, `type="email"`, `pattern` для телефона.
- **Модальное окно:** `<dialog>` с быстрой заявкой, закрывается кнопкой «×», «Отмена», клавишей Esc и кликом по фону.
- **CSS:** переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`, подсветка ошибок через `aria-invalid`.
- **Flexbox:** шапка, меню, кнопки в карточках, категории, подвал.
- **CSS Grid:** сетка карточек `products-grid`, hero-блок, каталог «фильтры + товары» (`grid-template-areas`), страница товара, страница заявки, подвал.
- **БЭМ:** блоки `site-header`, `site-nav`, `breadcrumbs`, `hero`, `advantages`, `products-grid`, `product-card`, `reviews`, `review`, `promo`, `categories`, `catalog-layout`, `catalog-filters`, `catalog-products`, `product`, `specs-table`, `order-layout`, `order-form`, `order-steps`, `order-dialog`, `contacts-list`, `faq`, `site-footer`, `to-top`, `button`.
- **Позиционирование:**
  - `position: sticky` — шапка сайта, блок фильтров в каталоге, блок шагов заказа;
  - `position: relative` + `position: absolute` — бейджи «Хит», «Новинка», «Скидка» на карточках;
  - `position: fixed` — кнопка «Наверх» и сообщение об успешной отправке;
  - `z-index` — шапка, кнопка «Наверх», сообщение (значения вынесены в переменные `--z-*`).

## Самостоятельные доработки

1. **Дополнительные блоки и компоненты:** отзывы покупателей, рекламный блок акции, частые вопросы об уходе за цветами (`details`/`summary`), блок «Как проходит заказ», список преимуществ в виде плиток.
2. **Собственное оформление:** тема цветочного магазина, свои SVG-иллюстрации букетов и растений, розово-зелёная палитра, градиентный hero-блок, тени и анимация карточек при наведении, тёмно-зелёный подвал с тремя колонками.
3. **Улучшенные карточки:** изображения, категории, бейджи через модификаторы (`product-card__badge--hit`, `--new`, `--sale`), старая цена для товара со скидкой, модификаторы `product-card--featured` и `product-card--discount`.
4. **Формы и сценарий заявки:** отдельная страница заявки с выбором товара и количеством; в модальном окне показывается выбранный товар; ошибки подсвечиваются и снимаются при исправлении; всплывающее сообщение об успехе исчезает через 5 секунд.
5. **Навигация и каталог:** расширенное меню, категории, фильтры с кнопками «Применить» и «Сбросить», «прилипающие» фильтры, трёхуровневые хлебные крошки, кнопка «Наверх», ссылки «Весь каталог» и «Подробнее».
6. **Доступность:** ссылка «Перейти к содержимому» для клавиатуры, заметный фокус, `aria-current` у текущей страницы, `aria-describedby` для подсказки к телефону, `alt` у всех изображений, отметка обязательных полей.
7. **Структура кода:** CSS разделён на 14 смысловых разделов, классы названы по БЭМ, нет стилизации через `id` и inline-стилей.
8. **Дополнительно:** `sitemap.xml` и Open Graph-теги с превью-картинкой.
